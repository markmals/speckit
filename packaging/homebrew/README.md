# Homebrew packaging

`brew install markmals/tap/specify` installs `specify` from a **bottle** —
a prebuilt binary that the tap's CI compiles once, not a download generated by
goreleaser. This is the Homebrew-native path.

## Why not goreleaser's `brews:`?

goreleaser still earns its keep: it publishes the cross-platform release archives
(`specify_<version>_<os>_<arch>.tar.gz`) that the **Mise plugin** and manual
`curl` installs download. A Homebrew bottle can't serve those — it's only
consumable by Homebrew.

But for Homebrew specifically goreleaser gives us nothing a bottle doesn't. Its
`brews:` block produced a *download-formula*: `brew install` fetched the
goreleaser archive at install time, with no bottle and no test-bot. So we dropped
it. Homebrew now goes through the tap's existing bottling CI (`brew test-bot` +
`pr-pull`), same as every other formula in the tap.

Net: **goreleaser → Mise + manual binaries; tap bottle → Homebrew.** No overlap.

## How it works

- [`specify.rb`](specify.rb) — the formula. From-source (`depends_on "go" => :build`),
  so the bottle is a real compile, reproducible from a tagged source tarball.
- [`update-specify.yml`](update-specify.yml) — runs *in the tap*. Bumps the
  formula's version + source `sha256` to the latest SpecKit release, commits, and
  lets `brew test-bot` bottle it. Triggered by a daily cron, manually, or — the
  fast path — a `repository_dispatch` that this repo's `release` workflow fires
  right after publishing (cross-repo via the `HOMEBREW_TAP_TOKEN` PAT).

These two files are the **canonical source**; the tap's copies are what actually
run.

## First-release checklist (one time, gated on `v0.1.0`)

1. Copy `specify.rb` → `markmals/homebrew-tap/Formula/specify.rb`.
2. Copy `update-specify.yml` → `markmals/homebrew-tap/.github/workflows/`.
3. Tag + push `v0.1.0` here → `release` workflow publishes archives and dispatches
   `specify-release` to the tap.
4. The tap's `update-specify.yml` fills in the real `sha256`, `brew test-bot`
   bottles it, `pr-pull` publishes. `brew install markmals/tap/specify` works.

After that it's automatic on every release.
